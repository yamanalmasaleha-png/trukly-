## 2. Concurrency, Data Integrity & Reliability Risks

1. **Lost Updates & Corrupt-File Data Wipe on Style Guide Workspace ([AUD-0013](03_COMPLETE_FINDINGS.md#aud-0013), `HIGH`)**:
   - `pushStyleGuideWorkspaceToGithub` snapshots `workspace-state.json` *before* 7–10 outbound GitHub API calls and overwrites the file afterward with stale `overrides_by_id`, destroying concurrent `save` edits. Meanwhile, `readWorkspaceState` silently returns `emptyState()` on JSON parse errors, wiping all 103 overrides on the next write.
2. **Poisoned `pg.Pool` Connections on Failed `ROLLBACK` ([AUD-0019](03_COMPLETE_FINDINGS.md#aud-0019), `HIGH`)**:
   - Both `packages/runtime-adapter/index.js:94-110` and `lib/db-tx.js:215-223` catch and ignore `ROLLBACK` errors while calling `client.release()` with no error argument—returning broken/aborted clients into an 8-connection pool.
3. **Kill-Switch Self-DoS & Incomplete `PAUSE_WRITES=all` ([AUD-0004](03_COMPLETE_FINDINGS.md#aud-0004), `CRITICAL` & [AUD-0014](03_COMPLETE_FINDINGS.md#aud-0014), `HIGH`)**:
   - Setting `BITESHARK_PAUSE_WRITES=favorites` halts *all* platform writes (`failClosedAll = true`), whereas `BITESHARK_PAUSE_WRITES=all` fails to halt 5 MiB photo uploads, visits, trails, onboarding uploads, style-guide saves, or support issues.
4. **Silent Failure of Push Batch Alerting ([AUD-0018](03_COMPLETE_FINDINGS.md#aud-0018), `HIGH`)**:
   - Key mismatch (`out.failed`/`out.sent` vs `out.failed_permanent`/`out.delivered`) keeps `worker_heartbeats.worker_status = 'ok'` during 100% permanent push delivery outages.
5. **Swallowed `SessionEligibilityError` & Soft-Deleted `idempotency_key` `500`s ([AUD-0017](03_COMPLETE_FINDINGS.md#aud-0017), `HIGH` & [AUD-0026](03_COMPLETE_FINDINGS.md#aud-0026), `MEDIUM`)**:
   - Concurrent session revocations on `/api/me/profile*` and `/api/account/context` trigger `500`/`503` responses (`retryable: true`) and false server error incidents; reusing an `idempotency_key` (`legp_idx_0`) after soft-deleting a visit, photo, trail, or collection throws unhandled PostgreSQL `23505` (`500`).
6. **4x Connection-Pool Fan-Out on `/api/me/profile` ([AUD-0033](03_COMPLETE_FINDINGS.md#aud-0033), `MEDIUM`)**:
   - `getPrivateOwnerProfile` opens `1 + 3` parallel `withTransaction` connections on an 8-connection pool after `server/admin-routes.js` already burned 2 unpinned `loadAccessContext` queries.

## 3. Operational & Infrastructure Safeguards Review (`deploy/` & `.github/`)

- **Verified Hardening**: `ProtectSystem=strict`, `ProtectHome=true`, `PrivateTmp=true`, `NoNewPrivileges=true`, `CapabilityBoundingSet=`, `UMask=0077`, cross-environment `InaccessiblePaths=` between `truckly-staging` and `biteshark-staging2`, GPG-encrypted backups (`truckly-staging-backup.sh`), and SHA-256 migration checksum verification (`scripts/run-migrations.cjs`).
- **Confirmed Operational Gaps**:
  1. `deploy/systemd/biteshark-staging2-api.service:39` omits `-/var/lib/biteshark-staging2/style-guide` from `ReadWritePaths` under `ProtectSystem=strict` (`EROFS` on deploy from repo) ([AUD-0020](03_COMPLETE_FINDINGS.md#aud-0020)).
  2. `/usr/local/lib/biteshark-staging2/backup-staging2.sh` referenced by `biteshark-staging2-backup.service` and `biteshark-staging2-ctl` is missing from Git ([AUD-0020](03_COMPLETE_FINDINGS.md#aud-0020)).
  3. `.github/workflows/truckly-source-review.yml:195-206` uses `PUSH_BEFORE..HEAD` on `push` events and omits `.github/workflows` + `package.json` from `RUNTIME_DIFF`, allowing a subsequent docs commit to bypass failed PostgreSQL/browser CI suites ([AUD-0020](03_COMPLETE_FINDINGS.md#aud-0020)).
