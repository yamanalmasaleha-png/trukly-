# Repository Directory & Release Packaging Map

| Path | Runtime Role | Shipped in Linux Release Tarball (`build:release`)? | Notes & Ownership Rules |
|---|---|---|---|
| `server/index.js` | Standalone HTTP & `pg.Pool` entrypoint | **Yes** | Validates startup env, OID `1082` `DATE` parser, `NOBYPASSRLS` check, graceful `SIGTERM`/`SIGINT` drain. |
| `server/app.js` | Central 10-stage HTTP router & static file server | **Yes** | Dispatches `/api/healthz`, `/api/auth/*`, `/api/_staging_gate_probe`, governance routes, domain routes, `/admin` HTML gate, and `public/` assets. |
| `server/routes.js` | Explicit 30-route manifest for `api/**/*.js` | **Yes** | Enforces `REGISTERED_DOMAIN_ROUTE_COUNT === 30`; places static `/api/trucks/*` ahead of `/api/trucks/:id`. |
| `server/admin-routes.js` | Governance, onboarding, invitations, moderation, support, readiness, features & diagnostics router (46 paths) | **Yes** | Mounted via `isGovernanceApiPath` in `server/app.js`. *(Branch `83181ba` also mounts `server/customer-exploration-routes.js`.)* |
| `api/**/*.js` | 30 domain route handlers (`bookings`, `catalog`, `community`, `favorites`, `notifications`, `owner`, `pager`, `schedule`, `trucks`) | **Yes** | Frozen 30-file layout preserved from the pre-VPS serverless architecture. |
| `lib/*.js` | Shared ESM backend domain, auth, RBAC, crypto, feature, map & diagnostics modules | **Yes** | `admin-governance.js`, `age-policy.js`, `authz.js`, `catalog.js`, `client-ip.js`, `dates.js`, `db-tx.js`, `diagnostics.js`, `discovery.js`, `env-compat.js`, `feature-controls.js`, `map-config.js`, `pager-notifications.js`, `request-context.js`, `standalone-auth.js`, `support-tickets.js`, `webpush-crypto.js` *(+ `customer-exploration.js`, `editorial-stories.js`, `photo-storage.js` on `83181ba`)*. |
| `packages/runtime-adapter/` | Workspace ESM package `@biteshark/runtime-adapter` | **Yes** | `AsyncLocalStorage` + `WeakMap` request/DB context adapter (`file:./packages/runtime-adapter`). |
| `public/` | Zero-build browser HTML, JS, CSS, PWA manifest, SW, icons & `/policies/*.html` | **Yes** | Served directly by `server/app.js` (`resolveSafePublicFile`). Never place secrets or server code inside `public/`. |
| `migrations/` | Sequential immutable PostgreSQL migrations (`001`–`026` on `a4e9f53`/`a2f0135`; `001`–`027` on `83181ba`) | **Yes** | Applied by `scripts/run-migrations.cjs` with SHA-256 checksum verification. |
