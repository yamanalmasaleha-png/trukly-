Active Administrator Scope

Admin: Mod Capabilities

  • Review vendor applications, request corrections, and record approval/rejection recommendations.
  • Moderate pending/reported community posts (approve, reject, hide, restore) with immutable content history.
  • Triage and respond to customer/vendor issues with separated internal vs user-visible notes.
  • Apply bounded temporary safety restrictions (up to 72 hours) on listings when urgent safety/accuracy issues arise.

Admin: Top Exclusive Controls

  • Final vendor ownership approval, rejection, permanent restriction, suspension, and reactivation.
  • Independent field verification & photo-rights confirmation management.
  • Approve or reject privileged Admin: Mod and Admin: Top invitations (with self-approval blocked).

  • Explicit, reason-audited Act on Behalf of Vendor operational support mode.
  • Modify controlled Feature Controls (enabled, paused, hidden, and staff_beta audience) while essential platform security and recovery paths remain permanently protected.

OPERATIONAL HARDENING · FIXED REVIEWED REGISTRY

Feature Controls

Safely pause, hide, or restrict optional, beta, demonstrative, or placeholder features without stranding existing inquiries, active pickup pagers, moderation history, or essential platform security.

Enforcement & Propagation Model

Server HTTP mutations and notification worker pre-dispatch checks verify PostgreSQL state live on every operation (0 ms cache). Open browser tabs resynchronize on tab focus/visibility, cross-tab BroadcastChannel events, 403/503 feature rejections, and every 60s while visible. Already-transmitted network push packets cannot be recalled.

Operator Emergency & Recovery Path

Authoritative environment kill-switches (PAUSE_WRITES, PUSH_PROVIDER_MODE, DISABLE_SUBSCRIPTIONS, DISABLE_NOTIFICATION_DELIVERY) always override database enabled settings. SSH recovery CLI: node scripts/manage-feature-controls.cjs --status or --reset-defaults --actor-email <top-admin> --reason "...".
